# fh1 landmark annotations — manual placements for assets we can't extract programmatically.
# Format:  asset_tag<TAB>blender_x<TAB>blender_y<TAB>radius<TAB>mode
# All coords in BLENDER world space (X, Y).  Z (elevation) is auto-derived from
# the nearest v42k7 transform within `radius` meters.
#
# Modes:
#   single   = one placement at the exact (x,y); no search.
#   snap     = find the closest v42k7 transform within `radius` meters and place there.
#   scatter  = place one instance at EVERY v42k7 transform within `radius` meters.
#              Use for dense props like haybale fields or fence runs.
#
# Asset-tag resolution: we strip _LOD\d\d / _NOLOD suffixes and pick the lowest-
# LOD-number variant of any matching pool entry. That way you only need the
# base name (e.g. `PLA_GC_GolfCart`).
#
# Lines starting with # are ignored. TAB-separated.
